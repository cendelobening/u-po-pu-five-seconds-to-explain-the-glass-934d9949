## The entry

`main.py` (pure Python standard library, no dependencies) writes the single
sentence a house cat would say in the five seconds after sweeping a glass
off the table — no apology, no confession, just the cat's case for itself —
to `entry.txt` inside the output directory named by `MAKEFUN_OUTPUT_DIR`
(default `/output`).

## Run

```sh
python3 main.py
```

The output file is written world-readable (`0644`).
